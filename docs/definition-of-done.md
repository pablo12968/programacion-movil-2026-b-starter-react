# Definition of Done — Parcial C2

Adaptación de la plantilla al PDF. Marcar únicamente tras verificar.

- [ ] Nueve documentos completados y commit de documentación previo al código.
- [ ] Cinco endpoints, filtros, ids incrementales, validación y errores del contrato.
- [ ] Manejadores dados conservados y prueba de ruta desconocida 404.
- [ ] CRUD Ionic real con cuatro rutas, ProductCard y capas requeridas.
- [ ] Lista con carga, vacío, sin resultados y error con Reintentar.
- [ ] Detalle completo y eliminación con confirmación.
- [ ] Formulario crear/editar, validación en línea y details del servidor.
- [ ] Kotlin compila/ejecuta tres productos, null safety y descuento 10 %.
- [ ] npm test pasa con al menos dos unitarias y dos de API nuevas.
- [ ] npm run lint y npm run build pasan.
- [ ] Flujo CRUD y recuperación comprobados en navegador móvil y escritorio.
- [ ] .env ignorado, .env.example presente; sin secretos ni node_modules en Git.
- [ ] README de ejecución y dos secciones en inglés de 3–5 frases.
- [ ] Rama feature/catalogo-productos, seis o más commits convencionales.
- [ ] PR descrito con checklist hacia main del propio fork.
- [ ] Enlace del PR entregado en Moodle antes del cierre del PDF.
